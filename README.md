## 📌 Project Overview

The Indian Crime Data Curation and EDA project focuses on
analyzing crime-related data to identify patterns,
discrepancies, and trends within the Indian criminal justice
system.

The project examines the relationship between:

- First Information Reports (FIRs) registered
- Charge sheets filed
- Crime categories
- Data-driven policing insights

Through data curation, preprocessing, and exploratory data
analysis, the project aims to support a better understanding
of crime statistics and promote data-informed decision-making.

---

## 🎯 Objectives

- Collect and curate crime-related datasets.
- Clean and preprocess raw data for analysis.
- Investigate discrepancies between FIRs and charge sheets.
- Identify crime patterns and trends.
- Perform exploratory data analysis.
- Create meaningful data visualizations.
- Generate insights that can support smart policing
  strategies.

## 🔍 Methodology

### 1. Data Collection

Identify and collect relevant crime datasets
containing information about FIRs, charge sheets,
and crime categories.

### 2. Data Curation

- Inspect the dataset structure.
- Identify missing values.
- Check for duplicate records.
- Standardize data formats.
- Prepare data for analysis.

### 3. Data Preprocessing

Perform the required transformations to ensure
the dataset is suitable for exploratory analysis.

### 4. Exploratory Data Analysis

Analyze crime-related variables to identify
patterns, trends, and relationships.

### 5. Data Visualization

Use Matplotlib and Seaborn to represent
important findings through charts and graphs.

### 6. Insight Generation

Interpret the analysis results and identify
potential implications for data-driven policing.

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.x
- JupyterLab
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Ayan-045/Indian-Crime-Data-Curation-and-EDA.git
```

### 2. Navigate to the Project Directory

```bash
cd Indian-Crime-Data-Curation-and-EDA
```

### 3. Create a Virtual Environment (Optional)

```bash
python -m venv venv
```

Activate the environment.

**Windows:**

```bash
venv\Scripts\activate
```

**Linux/macOS:**

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Launch JupyterLab

```bash
jupyter lab
```

Open the relevant analysis files from the
`code/` directory.

## ⚠️ Limitations

- Analysis is dependent on dataset completeness
  and accuracy.
- FIR registration and charge sheet filing are
  distinct stages of the criminal justice process.
- Differences between these measures should not
  automatically be interpreted as case outcomes.
- Findings depend on the available time period,
  geographic coverage, and crime categories.
