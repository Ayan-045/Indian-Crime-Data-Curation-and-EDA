# Indian-Crime-Data-Curation-and-EDA
A data curation and Exploratory Data Analysis (EDA) project aimed at enhancing smart policing in India by investigating the discrepancies between registered FIRs and filed charge sheets.

This repository leverages data curation and Exploratory Data Analysis (EDA) to provide actionable insights into crime patterns and improve smart policing strategies in India. The project specifically investigates a critical problem within the justice system: the significant gap between the number of First Information Reports (FIRs) filed and the charge sheets actually issued for major crimes like theft, burglary, kidnapping, and fraud.

By analyzing and visualizing this data, the project aims to optimize resource allocation, build community trust through transparency, and assist law enforcement in making informed, data-driven decisions.
